# 悬浮标题、窗口与照片区外层圆角、背景过渡：2026-10-21

本轮延续[照片页操作菜单](photo-page-actions.md)，按最新区域指认调整。圆角对象是右侧整块灰色外层面板，包含标题、图片间隙和留白，不是给网格顶边或单张照片额外裁切。

## 最终行为

- 标题、数量及独立圆形按钮固定在上层。滚动视口覆盖照片面板，起始空隙随内容滚走，照片会经过标题和按钮下方；滚动后仅添加无边框的顶部渐隐辅助阅读，不恢复整条玻璃栏。
- 灰色照片面板的圆角在 `LibraryShell` 包含整个 Navigator 的外层实现，半径 18，淡中性填充保持相册背景透出。与左侧相册面板统一上、下 8 像素间距；右侧同样留 8 像素。已撤掉误加在内层网格上的圆角裁切，单张照片仍为原来的 8。
- Linux 整窗半径 24，裁切范围包含背景、标题栏、页面和弹窗。GTK 使用 RGBA visual、透明窗口底色及透明 Flutter clear color，避免透明角落落在黑底上；缩放命中区留在视觉裁切之外。最大化/全屏外轮廓铺满，全屏照片面板取消额外圆角。未改变未配置透明原生底面的其他平台窗口外形。
- 切换相册保留最近完整背景；新缩略图拿到路径后先完成解码，才提交为新背景。旧图保持不透明，新图在上面以 420 ms easeInOut 淡入，避免双向淡出时露出纯色底。画面最多两张，过渡中只排队保留最新目标。
- 慢请求、失效请求及失败解码不能清空完整背景；减少动画立即切换。空结果、回收站或 gateway 更换仍立即清除旧图，保留隐私边界。没有新增原图读取或扫描。
- 分组/宽度变化的滚动锚点计入覆盖标题高度和行高比例。搜索切换期间可能同时挂载新旧 ScrollPosition，顶部渐隐读取最新 position，不通过要求唯一 position 的 `offset` getter。
