# 滚动位置驱动的节流背景：2026-10-21

照片页背景跟随当前可见内容，但不按每张图片或每个滚轮事件切换。

- 持续滚动时约每 1,200 ms 发布一次最新目标；停止 300 ms 后补上最后位置。只发布变化后的目标，不会因相同位置重复获取缩略图。
- 目标取固定标题下方到视口底部之间的中间位置，选该行中间附近的实际照片。非连续搜索分组使用真实 item rank，不按连续序号猜测。
- 滚到顶部恢复保存的相册封面（没有封面则首图）；手动设置新封面取消待处理的视口目标。没有改写相册封面或排序偏好。
- 节流状态独立于图库 DTO；滚动事件只更新待处理目标和计时器，不触发逐帧缩略图读取或额外扫描。
- 图页元数据暂未到达时保留旧背景，等可见页正常加载后再解析目标；目标变化立即使旧解码失效，即使新目标的 DTO 还没到。不同查询 epoch 不互相覆盖。
- 继续复用预解码与 420 ms 渐变，旧图保持不透明，最多绘制两张，快速目标变化只排队保留最新目标。高对比、减少动画、回收站/空结果规则保持。
