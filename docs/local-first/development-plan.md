# 一期纯本地：开发与验收顺序

版本：2。以下取代旧一期云同步顺序。S01工程共用；S02起使用本地LibraryId模型，云同步进入二期，不作为本地步骤的依赖。

每一步交付运行产物、复现命令、自动检查、真实输入/文件结果和缺陷记录。独立实现可以并发，依赖验收不可跳过。数据/文件操作使用隔离测试目录，不对用户真实图库做验收操作。

| 步骤 | 开发顺序与交付 | 必须通过的验收 |
|---|---|---|
| S01 共用工程 | Linux runner→Rust调用→配置绑定→事件与退出 | 正常窗口、UTF8往返、有序事件、正常关闭；摘要/协议错配拒绝；重复构建 |
| S02 独立本地库 | LibraryId/数据根→SQLite迁移/单writer→本地命令与查询→根锁/关闭 | 无账号无网络可建库；重启身份/收藏不丢；重复实例拒绝；回滚/迁移失败不清库 |
| S03 来源与缩略图 | 文件/目录选择→后台扫描→增量批入库→可见优先缩略图 | 不复制/修改所选原文件；首批发现即可查询；仅扫描支持范围，取消/坏图隔离；方向与缓存正确 |
| S04 真实浏览 | 网格分页/分组→查看器→缩放/平移/导航→收藏/元数据 | 正常UI打开实际图片；前后顺序/选择/键盘正确；重启收藏持久；失效原图不崩溃 |
| S05 十万图前置门槛 | 原生窄索引→rank窗口→预取/取消→full玻璃预算 | 10万项首屏≤2s目标；页P95≤50ms、跳转窗口≤100ms；60Hz帧/内存预算；无全量Dart DTO/大OFFSET |
| S06 组织与搜索 | 年月日布局→路径/手动相册→筛选/排序/搜索→多选 | 查询集合一致；拖动/hover不误切相册；搜索可取消且只用当前结果；相册操作不擅自移动文件 |
| S07 文件管理 | 操作意图→移除索引/回收站→恢复/永久删除→导出副本 | 各操作语义准确、必要确认；同名目标不覆盖；故障重启可恢复；原文件只在明确操作后变化 |
| S08 本地编辑 | 版本捕获→裁剪/旋转/翻转→基础调色→另存/退出保护 | 像素/方向结果正确；未保存退出可取消；源被外部修改不静默覆盖；保存失败保留源和草稿 |
| S09 监听与恢复 | 文件监听/合并重扫→来源失效→缓存修复→持久操作结算 | 外部增加/改动/删除准确更新；来源暂失不清历史；重启/缓存丢失不造假就绪；资源无泄漏 |
| S10 综合性能与UX | 十万数据矩阵→本地后台负载→长时内存→明暗/三宽度/玻璃 | full/auto分别测；扫描/缩略图/导出期间仍响应；DPR/冷缓存分开；真实合成下材质与无障碍通过 |
| S11 Linux安装交付 | 最终代码完整检查→bundle/启动器/依赖→安装后主旅程 | 安装目录从零添加/浏览/收藏/编辑/回收站/恢复/重启；构建/产物校验一致，实际跑分与限制齐全 |

## S02–S04首个本地可用版本

先建立“选目录→后台发现→缩略图→网格→查看器→收藏→重启”的完整切片。读取原图/解码在后台执行；首屏不等整目录扫描完成。SQLite结构化保存来源、媒体身份、版本和本地偏好，不持久化云图JSON，也没有虚构登录步骤。

S02的schema必须满足LibraryId独立、作用域外键、文件URI唯一、扫描/文件操作恢复、查询索引。S03预览只为可见窗口优先准备，不能在添加十万张目录时解码全部原图再放行。S04是真实文件与正式FFI路径，不能用widget里的示例列表代替。

## S05性能检查

保留[M16](../design/modules/16-performance.md)首屏、分页、跳转、UI/raster分位数、RSS/显存和句柄预算。基准条件与原始数据必须记录；不把平均FPS作为唯一结论。

前置夹具覆盖1千/1万/5万/10万，根组、稀疏收藏和深路径。S10重新测真实本地功能整合后结果；旧原型成绩不能直接转记到最终构建。

## S07/S08文件与原图保护

移除来源/索引只改变图库，不默认删除原始文件。移入系统回收站、恢复、永久删除和导出各自是独立命令；写前核对捕获版本和目标，文件结果与DB提交分步留下恢复证据。

编辑优先另存副本。任何覆盖保存入口必须明确确认、具备备份/回滚和源变化检查；能力未验收前不开放该入口。所选目录的物理相册与应用手动相册分开，不用界面分组操作隐式改文件树。

## S10综合负载

原云同步并行样本留给二期。一期将后台负载定义为扫描批入库、可见/预取缩略图、文件监听变化、编辑保存或导出；分别测及合法组合测，不让后台工作饿死输入或renderer。
