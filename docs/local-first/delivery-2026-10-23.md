## 修改范围

- 手机图库和相册的标题、计数、明暗背景与大字体布局；相册恢复固定三列。
- 手机照片页和相册页复用 Linux 端的索引、同步及上传提示。
- Android / Linux 共用统一方形缩略图栏：每张照片固定为随栏高度的方形（手机 48×48、桌面 60×60），用 `BoxFit.cover` 居中裁切，缩略图大小不随原图比例变化；当前项只放大 1.12 倍，移除选中色边框和背景。手机栏高度为 64，项间间隔手机 8、桌面 12。
- 缩略图栏准备等待最多 400 ms，随后允许现有预览/占位继续展示；已显示的栏不因后续准备重新透明，避免慢缩略图隐藏整条导航。
- 统一跳过来源内 `.` 开头的隐藏子目录，过滤其变更事件与入库；旧活动记录退出可见图库，保留原文件和收藏。Linux 系统/挂载点回收站、Android 内部回收站继续监听，回收站不作为普通照片重新扫描。
- Android 图片缩略图优先走系统 ImageDecoder，按目标尺寸解码、回收中间位图并以白色合成透明区域；失败时保留支持格式的 Rust 回退。原文件指纹复核、临时文件及原子发布保持有效。
- Rust 大 JPEG 缩小解码添加 64 KiB 读缓冲，消除压缩数据逐字节触发底层读取的问题。
- 视频播放使用硬件自动/MediaCodec 路径；Linux 视频缩略图先尝试 FFmpeg `-hwaccel auto`，不可用时重试软件路径；Android 视频缩略图优先请求缩小帧，失败时保留原帧回退。
- Android 解码能力、图片解码耗时和原生缩略图批次日志进入 logcat。软件位图仅代表缓存编码需要 CPU 可读输出，不等同于强制软件编解码器；设备不提供 JPEG/PNG MediaCodec 接口时不能宣称这些格式已全部硬解。
- 启动脚本支持 `--android-abi`，可通过现有入口构建、安装、启动与设备现有版本号匹配的分 ABI 包；同时保留本地原有的安卓启动、模拟器和文档修改。

例如：

```bash
./tools/run_app android --device SERIAL --no-avd --android-abi arm64-v8a --build
```
