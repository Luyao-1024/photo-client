# 手机端显示优化与模拟器验证（2026-10-23）

本轮继续优化手机端图库与相册的可读性。用户随后明确禁止在实体机器运行用例，因此运行期验证仅针对 `emulator-5554`，没有执行实体手机或真实桌面的测试用例。

## 修改

- 图库顶部增加随明暗主题变化的高遮盖渐变底色，覆盖状态栏、标题与计数区域，下缘渐隐。滚动时照片不会明显干扰文字；没有增加实时模糊。
- 标题下方只显示当前范围的项目数，移除当天完整日期，避免长日期挤占计数空间；照片日期仍保留在分组标题。
- 相册页固定三列；根据实际可用宽度计算封面大小，字体缩放只增加名称与计数所需高度，不减少列数。
- 相册名称最多显示两行，卡片高度为两行名称和计数预留按字体缩放计算的空间。页面标题及相册总数增加单行溢出处理。

## 后续修正：恢复三列

用户反馈实体手机上的相册被降为两列，屏幕实际足够容纳三列。原规则同时按卡片最小宽度与字体缩放减少列数，判断过于保守；现将智能相册和普通相册统一恢复固定三列，保留两行名称及按字体缩放计算的卡片高度。

本次修正仅执行相关 Dart 文件静态分析、Release 构建、覆盖安装与安装元数据确认，不在实体设备执行用例。下方模拟器记录属于恢复三列之前的版本，其中两列检查不代表最终行为。

## 后续修正：手机状态提示与 Linux 一致

手机照片页和相册页此前没有显示桌面端使用的 `LibraryActivityProgress`。现复用同一组件、同一缩略图状态数据、同一 `AppStrings` 文案及同步优先级，不另外新增手机端提示词：索引时显示“正在索引中 X/Y”，同步或上传时显示 Linux 端对应提示。

手机将状态放在标题下方的计数位置，使用紧凑排版；空闲时恢复照片数或相册数。桌面组件的默认排版与显示条件保持原样，相册固定三列。相关四个 Dart 文件静态分析通过；本次只做编译、安装及安装元数据确认，不在实体设备运行用例。之前的模拟器检查仍属于各自当时版本，不作为本次提示词的运行验收证据。
