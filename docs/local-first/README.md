设计版本：2。2026-10-20用户调整范围：先补齐纯本地功能，云同步留到二期。本目录是当前开发与验收的优先入口；旧`docs/design`中的云端步骤和账号数据模型作为二期参考保留。

S01已验收；S02–S04已完成组件检查并接通原生端到端链路（FRB绑定、`NativeCoreGateway` 实现本地接口、真实选择器、`--data-root` 隔离数据根、真实窗口旅程驱动）。阶段级真实验收以[阶段记录](progress.md)与 `docs/verification/S0x` 报告为准：组件通过不等于全流程通过，未执行项不伪报。

## 保留的总体决定

Flutter + Rust；Linux先交付；Android/Windows通过平台配置与ports接入；手机/平板/桌面共享响应式页面；100,000张图库边界验收；统一液态玻璃与可读性/性能回退。

S01工程、FFI、配置摘要和真实窗口验证为共用基础，继续完成。新的一期不实现账号登录、SyncServer HTTP、快照/增量、租约、上传下载和云端配额；应用本地流程不要求网络或账户。

## 一期本地功能

| 范围 | 需要交付的行为 |
|---|---|
| 文件来源 | 添加文件/目录、后台递归扫描、手动重扫、监听变化、来源状态和移除索引 |
| 图库 | 虚拟网格、年月日/文件夹分组、排序、搜索、收藏和本地相册、多选 |
| 查看器 | 本地图像、正确方向、缩放/平移、前后导航、全屏、元数据、键盘与触摸 |
| 文件管理 | 明确区分移除索引、移入回收站、恢复、永久删除；导出/另存副本 |
| 编辑 | 裁剪、旋转、翻转、基础调色；保存副本、源变化检查、未保存退出保护 |
| 可靠性 | SQLite持久状态、文件操作恢复、缓存管理、重启、来源失效/缺失处理 |
| 体验 | 明暗主题、液态玻璃、无障碍、快捷键、十万图流畅浏览 |

JPEG/PNG/WebP是初始格式验收基线；旧应用的其他图片/视频能力逐格式登记解码/预览/编辑范围，不能把“文件可索引”称为完整媒体支持。阶段验收先完成图片主流程，不用视频支持抵扣图片可靠性或性能。

## 本地身份与存储

1. `LibraryId`是本地图库身份，独立于任何云端用户；不创建虚构服务器账号来满足数据库外键。
2. 本地数据根拥有`library.sqlite`与私有缓存/操作暂存目录；SQLite由单writer管理。
3. 添加目录默认**引用并索引原文件，不复制整份图库**，以免十万张图片产生不必要的双份存储。来源路径属于平台适配器；未来Android可换成授权URI。
4. 显式“导入副本/保存副本”才写受管目录。普通浏览、收藏、相册编组只改索引或偏好，不改原图。
5. 修改/删除实际文件只能来自明确用户操作，执行前捕获源版本，跨文件系统与DB窗口通过操作意图恢复。
6. 二期以独立sync binding将云端账号/record关联本地MediaId；不会要求改成本地记录必须依赖账号的模型。

初步结构合同在[本地schema](contracts/local-schema.sql)。应用本地schema已落地，当前版本3；版本2通过增加本地偏好、相册偏好、媒体详情和文件恢复记录升级，不清空图库。旧41张云同步设计表不作为一期初始化迁移。
