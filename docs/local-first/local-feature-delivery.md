# 本地功能与UX扩展记录

日期：2026-10-21。范围：仅第一阶段纯本地功能。未增加账号、HTTP、同步开关、上传、下载或同步入口；相邻旧客户端与服务端未修改。

用户要求优先功能开发，新的测试用例、尤其UX用例后补。本记录区分实现与验证，不将以前版本的截图、旧用例结果或编译成功当成当前完整验收。

## 当前实现

- 来源：应用内文件/目录选择（路径输入、目录导航和文件多选，不打开原生标题栏子窗口）、递归扫描、取消与真实重试；来源状态、重扫和仅移除索引；启动重新检查已登记来源，目录变化监听及来源排除。正常数据根首次启动可以接入系统图片/视频目录；显式隔离数据根不会读取真实用户图库。
- 媒体：JPEG/PNG/WebP/GIF/HEIC/HEIF图片；MP4/M4V/MOV/WebM/MKV/AVI视频的索引、缩略图与本地播放；追加MP4型动态照片检测与播放。支持索引、预览、播放和编辑分别判断，不把HEIC/GIF/动态照片/HDR当作可编辑的普通JPEG。
- 浏览：原生窄身份索引、按位置窗口查询、每页100项和有界页面缓存；逻辑网格保留未加载区域尺寸，缓存淘汰不会删除滚动区域；日期/名称排序、年月日分组、收藏筛选。
- 搜索：文件名、日期、联合匹配；年/月/日、斜线、短横线、中文年月日与紧凑数字日期；图像/视频预览和按类型查看更多。查看器从搜索结果进入时保持媒体类型范围。
- 选择：查询级最多2,000项全选，明确提示上限；选中身份独立于分页缓存，批量操作不会因缓存淘汰悄悄漏项。
- 相册：文件夹派生、封面、拖动排序与持久化，新建、重命名、移除索引，以及照片复制/移动到相册。相册移除保留原始文件并排除后台重新接入。
- 文件管理：系统回收站及标准`.trashinfo`，恢复、清空、永久删除；系统外部删除/恢复/清空的本地对账。GIO无法移动的跨文件系统来源使用标准系统回收站布局，不退回应用私有回收站。另存副本与显式导出不覆盖已有目标。
- 编辑：查看器内侧面板、旋转、翻转、自由/比例裁剪、裁剪框移动与角点缩放、亮度/对比度/饱和度、重置、原图对比、保存副本与覆盖前确认。默认推荐保存副本。
- 文件保护：渲染与编码在数据库actor之外；按照片版本和真实源指纹拒绝覆盖已变化源；保存临时文件校验后发布，JPEG/PNG保留EXIF并规范方向；数据库提交失败恢复备份。保存与永久删除有持久记录供启动恢复，物理移动的数据库失败有回滚保护。
- 设置：通用、外观、照片与视频、存储与日志；主题、语言、材质质量与透明度、减少动画、日视图列数、排序与缩略图并发设置持久化；缓存空间与清理、日志级别与清理。缩略图并发在下次启动生效。
- UX：桌面侧栏持续可见，查看器在内容区内导航；相册列表独立滚动，小窗口可访问相册；总览按顶部上拉披露；沉浸模式静止2.5秒隐藏控制、移动恢复；真实系统全屏；分层Esc、快捷键说明、删除/收藏撤销提示避开胶片条；按照片拍摄日期优先显示标题日期。
- 窗口：禁用Gtk标题栏和系统装饰，应用内绘制最小化/最大化/还原/关闭；支持标题区域拖动、双击最大化、八方向边缘缩放。关闭请求经过编辑/扫描保护并等待偏好写入与本地核心停止。
- 材质：共享Chrome/Reading角色，表单不透明度地板，自动/完整/轻量/纯色质量；自动模式按持续绘制负载降低效果，减少动画与高对比不改变用户保存的选择。

## 运行依赖

Linux图片后端使用libheif和HEVC解码器，视频元数据/缩略图使用ffprobe/ffmpeg，播放使用libmpv。构建器优先使用系统libmpv开发包；Fedora缺少时，只向忽略目录`.tooling`下载并解包RPM，不安装或更改系统包。若系统缺少HEVC解码器，构建器从固定版本、SHA-256校验的pillow-heif归档中提取原生libheif/libde265库，不引入产品Python运行时。运行时依赖随bundle复制，主程序使用相对`lib/`、视频插件使用相对自身的RPATH，并按同一SONAME复用播放器库，避免重复装载导致原生崩溃。`tools/prepare_linux_media.py`不属于产品运行流程，不在浏览媒体时下载资源。
