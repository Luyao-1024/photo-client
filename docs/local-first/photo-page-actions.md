# 照片页标题与操作菜单：2026-10-21

在[全窗相册背景与完整透镜](photo-canvas-liquid-material.md)基础上，按本轮反馈精简照片页。

- 年/月/日胶囊宽度从 264 调为 216，高度 48，三段等宽，文字与指示线不变。
- 移除整个页头的玻璃面板。标题仍为 24 / w600，数量仍为 bodySmall（12）；两行文字直接放在相册背景上。照片滚动区域保留在标题下方，避免无底板的文字被滚动照片覆盖。
- 搜索与竖向三点各为独立的 48 圆形玻璃按钮；三点位于搜索右侧。打开搜索时输入框单独占一行，窄窗的搜索范围再换行，不挤占标题。
- 三点菜单有“设置相册封面 / 排序 / 多选”。封面项在有照片的真实相册内启用；全照片、收藏、搜索和回收站不冒充真实相册，显示进入相册的提示。
- 设置封面进入当前网格的选图状态，点击照片调用现有 `albumCover` 写入当前相册，刷新后侧栏与全窗相册背景一起更新。支持取消按钮、Esc、失败提示及继续重试；未点击照片或取消不写入。保存中的重复点击不会重复提交。背景也能加载当前页之外的已保存封面。
- 排序弹窗复用已有日期新旧、名称升降四种偏好与持久化接口；选中后更新浏览查询。等待菜单所在帧结束后再推入排序弹窗。
- 多选从零勾选开始，不自动全选。选项和批量操作放在独立的可横向滚动操作行，退出选择靠前，窄窗仍能直接退出；回收站清空操作也放在此行。
