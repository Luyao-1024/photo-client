# 手机查看器缩略图栏恢复与紧凑排版（2026-10-23）

此前手机查看器精简改动把整个缩略图栏限制为仅桌面显示。按本次要求，手机恢复同一套缩略图栏及导航逻辑，并采用较小的尺寸。

| 几何尺寸（逻辑像素） | 手机 | 桌面 |
| --- | --- | --- |
| 栏高度 | 64 | 84 |
| 普通缩略图尺寸 | 统一 48×48（居中裁切填充） | 统一 60×60（居中裁切填充） |
| 项间间隔 | 8 | 12 |
| 当前项放大倍数 | 1.12 | 1.12 |

手机栏高度比原共享尺寸减少约 24%。两端都把每张图统一放进随栏高度的方形缩略图：手机 48×48、桌面 60×60，用 `BoxFit.cover` 居中裁切，缩略图大小不再随原图长宽变化，横图、竖图和方图看起来一样大。项间间隔手机 8、桌面 12。当前项保持放大强调，首尾项也能居中。缩略图请求和解码按各端方形边长准备；手机不会继续按桌面尺寸准备图片。

- 支持横向滚动、点按切图、当前项自动居中；大图滑动翻页会同步选中项。
- 点按图片时，头部与缩略图栏一起隐藏、恢复。
- 手机没有鼠标悬停，播放视频时不再套用桌面“播放中隐藏、悬停恢复”的规则；缩略图栏可直接触控。
- 栏底部避开系统手势区。视频控件和浮动提示的预留空间随栏高度一起调整。

## 统一方形与当前项规则

按后续要求，Android 和 Linux 共用统一方形缩略图及选中样式：每张照片固定为随栏高度的方形（手机 48、桌面 60），使用 `BoxFit.cover` 居中裁切，缩略图大小不随原图比例变化。此前按原图比例计算宽度、再用 `BoxFit.contain` 显示完整画面的规则已被替换；完整画面由大图查看器展示。

当前项只放大为 1.12 倍，移除所有选中色边框、描边和填色；放大不改变分配宽度，切图时相邻项不会被挤动。保留独立的无障碍选中语义与常规键盘焦点行为。

条目宽度固定为“方形边长 + 间隔”，居中与可见范围按固定步长计算。首尾项分别预留足够空白；手动浏览缩略图栏时，加载远端页不会强制跳回当前照片。

统一方形的实现与验证记录在 [缩略图栏方形缩略图](filmstrip-aspect.md)；下方记录属于刚恢复紧凑栏时的版本。

## 验证范围

运行验证仅在 `emulator-5554` 上完成（1080×2400、420 dpi），使用现有项目入口构建并启动：

```bash
PHOTO_FLUTTER_ROOT=/home/luyao/.local/share/photo-client/flutter \
  ./tools/run_app android --device emulator-5554 --no-avd --build
```

通过 ADB 触控、UIAutomator 层级和截图完成了以下定向检查：

- 栏实际高度为 168 物理像素，对应 64 个逻辑像素；底部不压住手势区域。
- 点按缩略图从 2/9 切到 3/9，当前项中心为 x=540（容差 2 像素）。
- 大图左滑到 4/9，缩略图同步选中并居中。
- 点按隐藏、恢复头部和缩略图栏，隐藏时没有可点击的缩略图项。
- 横向拖动缩略图栏可看到末尾 HEIC，大图仍保持 4/9；点按最后一项切到 9/9 并居中。
- 视频播放至 00:01/00:04 时缩略图栏仍显示，播放/进度控件与栏没有重叠；点按下一张缩略图可从视频 1/9 切回照片 2/9。
