# Android / Linux 缩略图栏统一方形缩略图（2026-10-23）

Android 和 Linux 共用同一套 `ViewerFilmstripLayout`。每张照片固定使用随栏高度的方形缩略图：手机 48×48、桌面 60×60；图片以 `BoxFit.cover` 居中裁切填充。缩略图大小不再随原图长宽或 EXIF 方向变化，横图不会比竖图更宽，方图也不会更高。

- 条目宽度固定为“方形边长 + 间隔”：手机 8、桌面 12。
- 当前项只放大 1.12 倍，不改变条目分配宽度；不添加选中色描边、填色或阴影。
- 首尾独立留白、点按切图、当前项居中、选中语义与键盘焦点保持不变。
- 缩略图请求和解码按方形边长准备；完整画面仍由大图查看器显示。
- 此前“按原图比例显示、不裁切”的规则已被本轮替换；可变宽度、全景宽高限制和分页尺寸缓存不再参与缩略图栏布局。

## 验证

- `viewer_filmstrip_layout_test.dart`：手机 48 与桌面 60 两种高度下，任意索引的缩略图均为方形，条目步长固定；首尾、中间项的居中偏移与最大滚动位置一致；索引查找在负数与无穷远时正确截断。
- `viewer_filmstrip_test.dart`：桌面查看器缩略图为 60×60、`BoxFit.cover`，当前项在首项、末项和连续切换时保持居中。
- `mobile_layout_test.dart`：手机缩略图为 48×48，相邻中心间距 56（8dp 间隔），图片使用 `BoxFit.cover`。
- `emulator-5554` 实测：3:4、4:5、2:3、9:16 竖图与 4:3 横图的缩略图尺寸一致，间距均匀；截图见 `/tmp/filmstrip_square_portrait.png`、`/tmp/filmstrip_square.png`（本机临时文件，不入库）。
- 未启动 Linux 实体桌面窗口；桌面几何由 60 高度的布局用例覆盖，不代表 Linux 运行期视觉验收通过。
- 2026-10-23 后续在真实 Linux 桌面（XWayland，1280×720）启动最新 Release：查看器缩略图栏与手机保持同一方形规则，所有缩略图按方形尺寸和 `BoxFit.cover` 显示，间隔均匀，当前项只放大、无选中色描边；未做像素级颜色或 GPU 性能验收。桌面 60×60 与居中几何仍由 `viewer_filmstrip_test.dart` 断言。
