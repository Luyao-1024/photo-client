## 故障注入的最小切点

| 切点 | 必须证明的结果 | 归属 |
|---|---|---|
| 凭证意图前/写SecretStore后/账户提交后 | 无越账户凭证、孤儿可定向清理 | T04-03 |
| 页记录写一半/游标提交前/提交后事件前 | 页事务全有或全无，重放幂等 | T05-02、T07-02 |
| 仅原图/仅缩略图完成 | 新照片不进普通图库，更新保留旧版 | T07-03、T09-01 |
| intent已存/目录已提升/可见指针提交后 | 每个文件与SQLite窗口都可重启恢复 | T09-02 |
| records提交后丢响应/状态查询也超时 | 仍保留原operation_id和未知结果，不盲目新建 | T08-03 |
| 保活超时/明确失锁后成功响应迟到 | 不恢复旧轮、不清dirty | T08-02、T08-03 |
| 上行期间新收藏/切账号/改范围 | 版本与上下文保护有效，旧响应不覆盖新意图 | T04-04、T08-04、T14-02 |
| SQL_FULL/IOERR/文件缺失/文件占用 | 无空库自愈、无假Synced、完整旧版可保留 | T05-03、T09-04 |
| 事件溢出/索引构建期间大量变更 | 重取快照/索引，当前锚点与账号无错配 | T12-01、T16-06 |
| cache淘汰/快速反向滚动/切viewer | 取消有效、可见优先、内存与句柄有界 | T12-04、T16-05 |
| full玻璃/auto降级/减少动态效果 | 外观可读、不卡顿、质量轨迹如实记录 | T17-03、T17-04 |

## 阶段完成门槛

- L0：可运行Linux骨架、真实FFI/配置/根锁/数据库/凭证接口，窗口与glass基础组件spike；应用测试证据另列。
- L1：真实服务登录与可靠下行/双资源/完整浏览，先用1千/1万图库验证分页与渲染结构。
- L2：显式范围导入、租约上传、收藏、回执恢复、旧客户端互操作和错误隔离。
- L3：100,000项完整性能矩阵、明暗/三质量玻璃视觉与输入、安装后的Linux bundle；不接受“以后再优化”抵扣。

## 性能执行卡

每次报告固定填写：代码/构建/profile digest、硬件/驱动/磁盘、窗口像素/DPR/刷新率、照片量/目录/收藏分布、缓存条件、有效玻璃模式和降级、同步并行条件、脚本时长与重复次数。

输出首屏/窗口/跳转时延、UI/raster P50/P95/P99、长帧比例、RSS与GPU内存、cache命中/解码队列/取消数。CSV/trace保留原始样本，不只给平均FPS或截图。冷缓存、热缓存、full、auto、同步并行分开比较；失败和未执行必须保留。
