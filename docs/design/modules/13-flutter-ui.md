# M13 Flutter 界面与交互

## 职责与范围

Flutter 构建共享页面、响应式导航、输入和可访问性，Riverpod 管理展示状态。页面不直接访问数据库、网络资源能力 URL 或系统同步状态。

## 接口与数据

主要 provider：runtime、capabilities、currentAccount、accountList、libraryQuery、photoDetails、syncOverview、importBatch。key 至少包含 account_id/epoch，query 再包含 filter/order；切换账号时取消旧异步结果。

页面与命令：

| 页面 | 内容 | 写命令 |
|---|---|---|
| 启动/恢复 | 当前阶段、可操作错误、重试入口 | 明确的恢复重试 |
| 登录/连接 | 地址/用户名/密码、验证结果、zone、仅接收说明 | begin/accept/discard login |
| 图库 | 分页网格、收藏筛选、逻辑路径分组、同步摘要 | 显式导入、手动同步 |
| 查看器 | 本地预览→本地原图、缩放、收藏、前后照片 | set_favorite |
| 外观设置 | 系统/明/暗主题、液态玻璃质量、透明度、减少动效 | 全局外观偏好，不改变同步运行 |
| 同步设置 | 总开关、当前账号、范围、暂停/立即同步、任务详情 | accept configuration/pause/resume/select |
| 导入进度 | 已接受来源、准备/完成/失败数和逐项原因 | cancel/retry |

当前以本地一期方案为准：图库、编辑、系统回收站和来源监听属于一期；登录、账号、云端删除和同步设置留二期，不作为当前UI入口。回收站照片不出现在普通网格。

## 流程与状态

页面统一 AsyncState 为 Loading / Data / Empty / RecoverableError / Blocked。Data 可同时有 background_operation，不因每次计数刷新清空现有内容。

Linux一期按用户要求继承旧版桌面空间关系：固定240逻辑像素侧栏，内容区内部导航承载查看器；小于700时使用72像素图标栏并提供相册抽屉。相册区独立滚动，回收站和设置固定于底部。移动端底部导航随对应平台适配另行实现。窗口缩放保留筛选、当前照片和草稿，不用“重建 App”切换布局。主窗口不使用系统标题栏/原生窗口按钮，由应用绘制按钮并经本地窗口通道执行拖动、缩放、最小化、最大化、关闭和全屏。

网格窗口、原生rank索引与缓存遵守[M16](16-performance.md)，材质/控件/动效遵守[M17](17-liquid-glass.md)。首屏优先读取 100 项和摘要，后续 near-end 取页。LibraryChanged 前缘刷新加 300ms 合并；保持选中 EntryId 和 scroll anchor。设置隐藏时只记失效，重新显示后读取；同类查询同一时刻最多一个，读期间事件合并。

图像先目标尺寸缩略图，再 viewer 本地预览/原图；图像 cache 初始预算 128 MiB，按版本 ID/尺寸缓存，LRU 淘汰与 M09 lease 同步。新解码结果核对 displayed_entry_id、LocalVersionId 和 epoch，防止快速导航错图。

设置编辑使用 draft：展开、取消、无效值和无变化保存都不暂停任务；只有接受有效变更后提交配置，旧准入安全停止并按 M14 重新触发。任务暂停/继续按钮与详情展开独立，不把整行同时用作两种动作。

总开关关闭采用 D11 的“停止同步并保留待办”语义，文案明确；重新开启恢复尚未完成工作。首版不提供会清历史的重置按钮。

## 输入与可访问性

鼠标 hover 不激活路径分组或改变选中相册。明确 click/tap 激活；键盘 Enter/Space 语义正确。手机触摸目标初设至少 48 logical px；图像覆盖控件保持简洁，提供名称和选中状态。

查看器支持左右键、Esc 返回、Ctrl+滚轮/触摸缩放，手势与网格滚动互不抢占。首版可无复杂滑动转场，但边界返回、焦点恢复和选择不可丢失。

所有用户文案通过本地化资源，先提供 zh-CN/en；错误用安全 message_key，不显示 Rust debug。图标按钮有 tooltip/semantics label；缩放后布局仍可访问核心操作。关闭窗口有未完成导入/同步时告知停止并可重启恢复，确认不会把未提交任务伪报完成。

## 异常与恢复

认证过期在当前账号设置聚合提示，照片仍可离线浏览；不为每张照片重复铺满相同错误。单图独有失败可在详情呈现，并提供诊断引用。配额、网络和本地空间错误分别给出对应操作。

PageInvalidated 从锚点重取；账号切换清空旧账号渲染与内存媒体缓存，避免新账号首页闪现旧图。布局预览只证明 Linux 上窄宽布局，不作为 Android 真机交付。
